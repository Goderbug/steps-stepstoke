# SDK function inventory

The public Node entry point is `sdk/index.mjs`; the browser entry point is `sdk/browser.mjs`. Both export the shared functions below. Neither has a signer, private key, automatic chain switch, broadcast loop or administrative authority. Prepared writes are **bytes for a separate wallet confirmation**. A caller can always bypass the UI and call a permissionless contract, so every write still needs on-chain checks described in [entry points](ENTRYPOINTS.md). A transport/read failure leaves state unknown; it does not authorize a repeat purchase.

| Functions or constants | Use; permission and failure mode |
| --- | --- |
| `createProject`, `proposeWork`, `continueWork`, `sponsorProposal`, `retryRefused`, `bindResult`, `forkHistory`, `approveExact` | Anyone may generate unsigned calldata. `continueWork` is the propose alias. Local invalid address/struct/amount/witness/raw hash/size rejects; the chain can still revert for state, price, allowance, Intake or gas. `approveExact` is a separate ERC-20 call; no helper sends it. |
| `canonicalWitness`, `witnessHash`, `validateProposal`, `nextOutputPath`, `keccak256Bytes` | Pure witness/proposal and path calculations. Reject malformed/sortedness/limits/unsupported target or bytes. A locally calculated hash without an authenticated checkpoint is no authority. |
| `previewProposal`, `readState`, `readFactory`, `readAllowance`, `readBalance`, `readPrice`, `toWalletRequest` | Prepare `eth_call`/wallet request only. Bad method/args/address/chain/account rejects. Read responses and current price may be stale by the time a wallet signs; `toWalletRequest` never sends. |
| `decodeRead`, `decodePreview`, `queryPrepared`, `queryState`, `queryPreview` | Decode a supplied return or execute a bounded caller-supplied provider read. ABI mismatch, RPC failure or revert rejects. An `eth_call` preview is not a purchase or price reservation. |
| `decodeCheckpoint`, `recoverHistory` | Decode explicit chain logs/checkpoints and require consistent Branch provenance. Missing, forged or contradictory supplied data rejects; neither function reconstructs missing bytes or treats a local journal as settlement. |
| `verifyManifest`, `strictJSON`, `strictManifestJSON`, `unsignedJSONInteger`, `utf8Length`, `decodeUTF8` | Strict raw JSON/UTF-8 and finite integer checks. Hash mismatch, malformed/duplicate/over-complex envelope, missing/ambiguous declared output or invalid integer rejects. Parsing alone does not bind on chain. |
| `createFileVerifier`, `verifyFile`, `fileCap`, `nodeSha256` (Node), `browserSha256`, `webCryptoSha256` (browser) | SHA-256/length/MIME checks on actual file bytes. Wrong descriptor, unsupported MIME, oversized/missing bytes reject. File validity never changes Branch state. WebCrypto cross-check can fail in an insecure context. |
| `artifactURL`, `originalResultURL`, `intakeObservationURL`, `fetchOriginalResult`, `observeIntake`, `observeAdmission`, `readLogs` | Build fixed official read URLs, fetch bounded original result bytes, correlate HTTP job admission or query bounded chain logs. Invalid hash/URI/chain/payer, redirect, unavailable endpoint, raw-byte mismatch, ambiguous request or overlarge range rejects. HTTP/Git is diagnostic only. |
| `EventLogCache`, `observeTransaction` | Cache logs under an explicit deployment identity with cursor-block reorg checks; inspect canonical receipt/depth (default 12 confirmations). RPC gap, reorg, old history, 10,000-log cap or pending receipt yields failure/incomplete/unknown, never settlement or a resubmission decision. |
| `canonicalJSON`, `abiHash`, `relativeAsset`, `validateHandoff`, `deploymentIdentity`, `verifyHandoffAssets`, `loadPublicHandoff` | Validate the exact named three-contract handoff and export inventory. Unsafe path, missing asset, wrong hash/ABI/identity, absent handoff, redirect or oversize rejects. A handoff still requires on-chain receipt/code/source verification. |
| `validateDeploymentRecord`, `assertProductionGates`, `validateReleaseState`, `uiCapabilities` | Validate deployment identity/gate evidence shape and derive UI capabilities. Missing/mismatched chain-1 deployment, incomplete five profiles or any open gate fails closed. JSON flags alone are not independent proof or on-chain access control. |

Shared exported constants `ASSET_TYPE`, `LIMITS`, `MANIFEST_LIMITS`, `PHASES`, `PROFILES`, `PROFILE_IDS`, `PUBLIC_SERVICES`, `REQUIRED_GATES`, `APPLICATIONS`, `RUNTIME`, `ethersVersion` and `interfaces` describe ABI/limits/service defaults; they confer no permission. The browser also exports `ArtifactFetchError`, `createArtifactPolicy`, `createLoopbackFixturePolicy`, `isAllowedArtifactURL`, `fetchTrustedArtifact`, `readBlobBounded`, `verifyHTMLExport` and `base64`: these enforce trusted HTTPS/loopback, no redirects, bounded byte reads and exact file checks; unsafe origins, unavailable CORS/stream, descriptor mismatch or size excess fail closed. The Node-only `sdk/files.mjs` exposes `ArtifactFetchError`, `isPublicArtifactAddress`, `fetchPublicArtifact`, `readArtifactFile` and `verifyHTMLDist`; unsafe IP/redirect/path, missing local file or content mismatch rejects.

Direct module imports add `sdk/config.mjs` (`readCode`, `verifyRuntime`, `publicConfigStatus`, `observeDeployment`, `observeLocalDeployment`, `verifyDeploymentConfig`) and `sdk/deployment.mjs` (`verifyBoundRuntime`, `verifyPublicDeployment`). Public observation requires an already selected chain-1 provider and the actual inventoried handoff/receipt/creation traces/source/runtime; local observation requires chain 31337. Wrong chain, missing historical RPC/trace, wrong immutable, compiler/ABI/policy drift or mismatch rejects. These reads do not switch a wallet or enable payment. `sdk/files-browser.mjs` exports the same browser file helpers directly.

The CLI exposes the same preparation and read groups with exact options in `node cli/relay.mjs help`. [CLI.md](CLI.md) explains the deployment importer and free preflight. Product operation and recovery rules remain in [OPERATIONS.md](OPERATIONS.md).
