# Unhosted read-only resolver proposal

No resolver server or hosting is implemented or claimed. This proposal is justified by a reproduced limitation: current official Markdown and PNG `/artifacts/<sha256>` requests returned HTTP 200, correct descriptor bytes and no redirect, but omitted `Access-Control-Allow-Origin`. Chromium on the exported static page refused both CORS reads. Raw headers, descriptor/hash/format checks and browser diagnostics are archived with integration evidence. Mocked HTTPS tests do not establish real CDN/CORS availability.

Preferred remedy: the official immutable artifact and original-result endpoints enable appropriate CORS themselves. Until then, use the delivered explicit manual original-file selection or Node CLI and keep the production compatibility gate open.

If independently approved later, the smallest resolver is stateless GET/HEAD only, with no arbitrary URL parameter: `/artifact/<64 lowercase SHA256>` maps only to `https://api.imd.fun/artifacts/<hash>`; an original-result route admits only a fixed API snapshot ID or validated CID plus the literal `/result.json`, with fixed reviewed HTTPS IPFS gateways. The browser supplies its authenticated descriptor or callback hash locally, never a key. Enforce fixed origin/path allowlists at every upstream hop, at most three redirects, public-address DNS checks with connection pinning, bounded time/bytes/concurrency, no cookies/authorization/referrer, and SHA-256/length/media or raw-keccak verification before serving. Reject other paths, private addresses and arbitrary status URLs. Send restrictive CORS, content-type, no-sniff and sandbox headers; do not execute returned content.

The resolver must have no RPC mutation, wallet, key, account, nonce management, signing, settlement, retry, persistent database or admin recovery endpoint. It cannot confer acceptance or retry rights. Reproduce success/error/CORS behavior against the approved host and update the inventoried export only after the requester separately authorizes that integration. No hostname, deployment receipt or hosted availability is invented here.
