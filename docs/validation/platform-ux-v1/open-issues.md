This supports a navigation-cancellation explanation for this reproduction, not a general resolution of every historical RPC error. The failing records remain retained. No screen-reader session, native 200% zoom or live-wallet/passkey/mobile-app transaction was performed. Named test wallets forward unsigned SDK calls only to disposable Anvil accounts. No live purchase is implied by the fixture or component showcase.
