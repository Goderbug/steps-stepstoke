# SDK, CLI and read-only tools

The Node SDK (`sdk/index.mjs`) and browser SDK (`sdk/browser.mjs`) share encoding, canonical witnesses, strict raw parser, exact runtime verification and limits. Vendored ethers is the delivered runtime dependency. Root `cto-relay`/package identifiers remain technical compatibility names; the product is STEPS/Stepstoke.

`verifyManifest(raw, recordedHash, proposal)` selects the unique `proposal.outputName` / `proposal.outputPath` entry among all produced files. The descriptor alias `{name,path}` is also accepted. Multi-file results require this context and never default to the first file. Existing single-file calls without context remain supported. Name/path collisions, missing output, malformed JSON and bounds violations reject; other produced files do not become accepted assets. `bind` still submits the complete original bytes and never triggers funding.

Run `node cli/relay.mjs help` for exact options. Commands return unsigned calldata or read requests; they never sign, broadcast or retry. `create`, `propose`, `preview`, `sponsor`, `retry`, `bind`, `fork`, `read`, `witness`, `decode-checkpoint` and `recover-history` preserve their prior argument separation. Amounts are integer base units (IMD has 18 decimals), never floating point. The SDK's `approveExact` prepares a separate exact Branch allowance; approval is not purchase.

`result-fetch --uri URI --hash CALLBACK_KECCAK [--gateway HTTPS_IPFS_BASE]` fetches original bytes, enforces the recorded hash and 32 KiB bound, and returns raw hex. It does not parse and reserialize. `intake-read --tx ORIGINAL_PURCHASE_HASH` reads `GET /intake/1/<hash>` with `settlement:false`. `file-check`, `html-check` and `fetch-check` check descriptor/content integrity only. Supplied file paths are explicit operator inputs, never filesystem paths copied from an untrusted manifest.

`observeDeployment(provider,{release,factory,chainId:1})` requires the provider already be on chain 1. `observeLocalDeployment` is deliberately limited to chain 31337. Exact runtime validation normalizes only compiler-reported immutable slots and requires repeated slots for each immutable to agree, then validates actual dependency getter values. ABI/code/policy drift fails closed. A public provider must be explicitly chosen; no function silently switches a wallet.

`node tools/observe-ethereum.mjs [DIST_DIRECTORY] [HTTPS_RPC]` verifies the actual inventoried handoff and receipt/code evidence without signing. A Factory address alone is not deployment provenance. See [HANDOFF.md](HANDOFF.md).

`node tools/check-official-bodies.mjs` runs the candidate encoder on its own disposable local chain and prints exact raw request bytes and hash for every profile/open/continue case. Adding `--free-check` sends only `POST https://api.imd.fun/requests/check`; this is free validation and never an order. The built-in Markdown descriptor and parent are explicitly sourced public observations; HTML inputs are labelled local fixtures and expected to be refused by public validation. These samples are not ready-to-buy user requests or live proof. `tools/validate-live.mjs BODY_OF_RESULT_JSON` only makes a preflight packet from an actual eth_call result and contacts no service.

The original result callback/event and exact chain checkpoint remain the authority. No SDK, CLI, file download, local journal, Git record or free check can move a Branch out of Pending/Recorded/Frozen or authorize a new purchase.

## Integrated deployment workflow

`continue --branch ADDRESS --proposal FILE --witness FILE` and SDK `continueWork` prepare only a proposal. They do not sign, select a new payer, infer a continuation parent from a file, approve or purchase. Inspect/history use `read`, checkpoint decoding and `recover-history`; funding uses a separately prepared `approveExact` followed by `sponsor` or explicitly authorized `retry`.

After a real official handoff and the final static build, run `node tools/import-deployment.mjs RECEIPT_EVIDENCE HTTPS_RPC` from the repository root. It reads the actual `.imd/reads/deployment.json`, optionally `.imd/reads/network.json`, and pinned ABI arrays. It requires the handoff source commit in the local Git object set, with every compiler-input source matching the frozen build. It never fetches a project head. The importer removes a stale export manifest before validating and writes `dist/imd-deployment.json` only after all source, receipt, trace, code and byte checks pass. Missing handoff is unavailable, not a placeholder. See [HANDOFF.md](HANDOFF.md) for exact evidence requirements.

`node tools/observe-ethereum.mjs [DIST_DIRECTORY] [HTTPS_RPC]` validates the same inventoried handoff the browser reads. It checks the deployment rather than accepting an arbitrary Factory address. A read-only RPC override changes transport, never addresses or chain. A provider lacking `debug_traceTransaction` with `callTracer` or historical code fails closed. Deployment verification does not close live/profile/security gates.

`admission-read --tx ORIGINAL_PURCHASE_HASH --request REQUEST_ID --payer BRANCH --intake OFFICIAL_INTAKE [--job JOB_ID]` correlates the official HTTP observation to the chain-1 transaction/request/Branch payer and callback target. It constructs a fixed official job URL, checks job ID and `paidBy`, and reports admission, execution and Git independently. It never follows a supplied status URL, signs, changes contract state or unlocks a retry. The UI exposes the same read-only observation separately from its authenticated attempt stages.

The final encoder generator emits twenty vectors: root open/continue and historical-child first-open/continue, each across five profiles. Sixteen current free checks have no blockers; four HTML-update cases use an explicitly local fixture and are refused `invalid_artifacts`. Neither structural acceptance nor a known public result replay proves live STEPS compatibility.
