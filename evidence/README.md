# Evidence index

All evidence is local. Tests deploy Factory/Branch code in the Foundry EVM and install the documented Intake/token mocks at the fixed protocol addresses. No public-chain transaction, funded key, real IMD consumption or paid runtime job was used.

- `forge-build.txt`: final compiler, code size and lint output.
- `forge-test.txt`: final default root suite, with the task's supplied fuzz seed.
- `forge-fmt.txt`: final `forge fmt --check` output/status.
- `node-test.txt`: offline SDK/CLI tests, including integrity checks for every vendored lockfile tarball.
- `limits-initial-trace.txt`, `combined-limits-initial-trace.txt`: diagnostic measurements of the initial limit candidate, retained to explain the repair.
- `max-binding-trace.txt`: maximum-field 16-asset binding measurements at the final raw manifest limit.
- `check-results.json`: command exit statuses and evidence references.
- `metrics.json`: machine-readable limits/readiness and measured call budgets.

Manifest/file fixture bytes are under `test/fixtures/`, and embedded Solidity equivalents are generated by `tools/generate-fixtures.py`. Tests never read fixture files through a cheatcode. The raw fixture manifests are local protocol-shape simulations, not writer-signed or publicly deployed job evidence.

`docs/REVIEW.md` records local review findings and repairs, and explicitly identifies the independent/live work that remains unperformed.
